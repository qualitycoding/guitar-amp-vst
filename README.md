# GrimAmp

Rock & metal guitar amp simulator audio plugin (VST3/AU/Standalone), spanning
70s blues rock to high-gain black metal and beyond. Seven genre voicings on one
parametric engine, 8 factory cabinet IRs (+ user IR slot), 24 factory presets,
and every control automatable in Ableton Live 12.

Built with JUCE 8 (pinned submodule) + CMake, C++20.

## Build

```bash
git submodule update --init --recursive
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release --target GrimAmp_VST3
ctest --test-dir build --output-on-failure -C Release
```

On Windows use "x64 Native Tools" (or Developer PowerShell) for the configure
step. The AU target is macOS-only (skipped automatically elsewhere).

## Install

- **Windows:** copy `GrimAmp.vst3` to `C:\Program Files\Common Files\VST3\`
  (requires elevated write access), then rescan in Live (Settings -> Plug-ins).
- **macOS:** copy `GrimAmp.vst3` to `/Library/Audio/Plug-Ins/VST3/` and
  `GrimAmp.component` to `/Library/Audio/Plug-Ins/Components/`, then rescan.

User presets live in `%APPDATA%\GrimAmp` (Windows) or
`~/Library/Application Support/GrimAmp` (macOS).

## Validation

- Frozen unit/DSP suite: `ctest --test-dir build --output-on-failure`
- Host validation: `pluginval validate --strictness-level 5 build/GrimAmp_artefacts/Release/VST3/GrimAmp.vst3`

## Layout

- `Source/` — processor, editor, parameters, DSP chain (`Source/DSP/`), presets
- `tests/` — frozen test suite (TEST_SPEC.md), bench harness, fuzz/loudness tools
- `Resources/ir/` — factory cabinet IRs (see PROVENANCE.md)
- `Resources/presets/` — 24 factory presets (APVTS XML snapshots)
- `plan/`, `premortem/`, `research/` — planning artifacts from the generation run
